A modern analysis chain for double-sided silicon-strip detector (DSSD) telescope data:

- A **MIDAS-to-ROOT** converter for the Daresbury data format.
- Event building, strip matching, energy/time calibration and particle identification for two
  DSSD telescopes, written in ROOT/C++.
- Replaces the legacy SunSort workflow, so analysis is reproducible and version-controlled.
